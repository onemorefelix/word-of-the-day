Ступені порівняння прикметників

Вибір між -er/-est і more/most залежить від довжини слова (кількості складів), а не від самого значення прикметника. Це механічне правило, яке варто довести до автоматизму, щоб не зупинятись і не думати щоразу.
✦
1 -er / -est — короткі прикметники
Односкладові слова, і двоскладові, що закінчуються на -y.
Один склад
Додаємо -er для порівняльного ступеня, -est для найвищого (+ the).
"old → older → the oldest" / "fast → faster → the fastest"
Два склади, закінчення на -y
Y змінюється на i перед -er/-est.
"happy → happier → the happiest" / "easy → easier → the easiest"
Орфографія: подвоєння приголосної, зайва -e
Коротке слово з одним голосним + одним приголосним у кінці — приголосна подвоюється. Слово, що вже закінчується на -e, отримує тільки -r/-st.
"big → bigger → the biggest" (подвоєння g)
"nice → nicer → the nicest" (тільки -r, не -er)
✦
2 More / most — довші прикметники
Двоскладові (окрім -y) і всі прикметники від трьох складів.
Формула
Сам прикметник не змінюється, more/most додається окремим словом перед ним.
"expensive → more expensive → the most expensive"
"modern → more modern → the most modern"
✦
3 Винятки й рівність — as...as
Кілька прикметників не підпорядковуються правилу за складами, і є окрема конструкція для "так само, як".
Неправильні форми
Найчастіші винятки, які не утворюються за жодним із правил вище — просто запам'ятовуються.
"good → better → the best"
"bad → worse → the worst"
"far → further/farther → the furthest/farthest"
As...as — рівність
Коли дві речі однакові за якістю, а не одна перевищує іншу.
"This book is as interesting as the last one." (не more interesting — вони рівні)
"She isn't as tall as her sister." (заперечення — менша за)
✦
Швидкий орієнтир: один склад чи двоскладове на -y → -er/-est. Два склади (не -y) чи більше → more/most. Завжди перевіряй перелік винятків окремо (good/bad/far). Джерело: British Council LearnEnglish — Comparative and superlative adjectives.
