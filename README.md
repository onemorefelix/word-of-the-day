# Слово дня — прототип

Статичний сайт (PWA): щоденне англійське слово з визначенням, транскрипцією та перекладом на українську. Ніякого бекенду — усе тягнеться напряму з безкоштовних публічних API прямо в браузері.

## Як це працює

- **Список слів** — вбудований масив у `index.html` (~90 слів середнього-просунутого рівня). Слово дня обирається за днем року, тож воно одне на всіх і однакове весь день. Можна редагувати список як завгодно.
- **Визначення + транскрипція** — [Free Dictionary API](https://dictionaryapi.dev/) (без ключа, без ліміту для особистого використання).
- **Переклад на українську** — [MyMemory API](https://mymemory.translated.net/) (без ключа, безкоштовний ліміт ~5000 слів/день — з головою вистачить на одне слово в день).
- **Кнопка "Наступне слово"** — гортає по списку вручну, якщо хочеться подивитись більше за раз.
- **manifest.json + sw.js** — щоб на телефоні можна було зробити "Додати на головний екран" і воно виглядало як окремий застосунок (з іконкою, без адресного рядка браузера), плюс кешується оболонка сторінки для швидкого відкриття.

## Розміщення на GitHub Pages (безкоштовно, без сервера)

1. Створи новий репозиторій на GitHub, наприклад `word-of-the-day`.
2. Заливаєш туди 4 файли: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`.
3. У репозиторії: **Settings → Pages → Source → Deploy from branch → main / (root)**.
4. Через хвилину сайт буде доступний на `https://твій-нік.github.io/word-of-the-day/`.

## Підключення власного домену (pp.ua)

1. Реєструєш домен, наприклад `slovo.pp.ua`, на реєстратора, що видає pp.ua (nic.ua або подібний).
2. У DNS-налаштуваннях домену додаєш CNAME-запис:
   - Host: `slovo` (або `@`, якщо кореневий)
   - Value: `твій-нік.github.io`
3. У репозиторії створюєш файл `CNAME` (без розширення) з одним рядком — твоїм доменом: `slovo.pp.ua`
4. У Settings → Pages вписуєш той самий домен у поле Custom domain, чекаєш DNS (зазвичай до кількох годин), вмикаєш "Enforce HTTPS".

Після цього сайт живе на твоєму домені, повністю безкоштовно, без жодного сервера, який треба підтримувати.

## Встановлення на телефон

- **Android (Chrome):** відкрити сайт → меню (три крапки) → "Додати на головний екран".
- **iPhone (Safari):** відкрити сайт → кнопка "Поділитися" → "На екран «Домівка»".

Це не системний віджет у строгому сенсі (обмеження iOS/WidgetKit ми обговорювали), але іконка з'являється на головному екрані, відкривається на весь екран без браузерної обгортки, і працює офлайн для вже завантаженої частини.

## Куди розвивати далі

- Зберігати "я знаю це слово" в `localStorage`, щоб не показувати вивчені слова повторно.
- Додати озвучку слова через `SpeechSynthesis` API (вбудований у браузер, безкоштовно).
- Розширити список слів або підвантажувати його з окремого JSON-файлу за рівнями складності (A2/B1/B2/C1).
- Справжній Android-віджет (не просто PWA-іконка) — це вже Kotlin + AppWidgetProvider, окрема історія, але не потребує Mac.
