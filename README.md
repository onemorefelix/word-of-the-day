# Базис — тренажер слів і часів (PWA)

Статичний застосунок: 50 англійських слів і дієслів з перекладом, формами часів, прикладами речень у Present/Past/Present Perfect та коротким поясненням типових плутанин. Прогрес зберігається на пристрої (localStorage), інтервальні повторення — як спрощений Anki (1 → 3 → 7 → 14 → 30 днів).

Жодного бекенду, жодного зовнішнього API — усі дані вшиті прямо в код, тому працює миттєво і повністю офлайн.

## Файли

- `basis.html` — сам застосунок (це головний файл, більше нічого відкривати не треба)
- `manifest.json` — опис PWA (назва, іконка, колір) для "Додати на головний екран"
- `sw.js` — service worker, кешує застосунок для офлайн-роботи
- `icon-192.png`, `icon-512.png` — іконки застосунку

## Розміщення на GitHub Pages (безкоштовно)

1. Створи репозиторій, наприклад `basis-app`.
2. Заливаєш усі 5 файлів вище в корінь репозиторію.
3. **Settings → Pages → Source → Deploy from branch → main / (root)**.
4. Сайт з'явиться на `https://твій-нік.github.io/basis-app/basis.html`.

Якщо хочеш, щоб застосунок відкривався прямо з кореня (без `/basis.html` в кінці), перейменуй `basis.html` на `index.html` перед заливкою — тоді буде просто `https://твій-нік.github.io/basis-app/`. Не забудь тоді поправити `start_url` в `manifest.json` на `./index.html`.

## Підключення домену pp.ua

Той самий принцип, що і раніше:
1. Реєструєш домен на nic.ua (чи іншого реєстратора pp.ua).
2. CNAME-запис: Host `@` (чи піддомен) → Value `твій-нік.github.io`.
3. Файл `CNAME` в репозиторії з текстом домену всередині.
4. Settings → Pages → Custom domain → вписуєш домен, чекаєш, вмикаєш HTTPS.

## Встановлення на телефон

- **Android (Chrome):** відкрити сайт → меню → "Додати на головний екран".
- **iPhone (Safari):** відкрити сайт → "Поділитися" → "На екран «Домівка»".

Іконка з'явиться як окремий застосунок, відкриється на весь екран без браузерної обгортки, працюватиме офлайн (окрім першого відкриття, коли треба один раз завантажити сторінку).

## Прогрес і дані

Весь прогрес зберігається в `localStorage` браузера **на цьому конкретному пристрої**. Якщо перевстановиш браузер, очистиш дані сайту, або відкриєш на іншому телефоні — прогрес почнеться заново. Це нормально для MVP; якщо згодом захочеш синхронізацію між пристроями — знадобиться або хмарне сховище (Supabase, той самий стек що в Farm Finder), або просто експорт/імпорт прогресу вручну.

## Куди розвивати далі

- Додати наступну партію слів (наступні 50, чи тематичний набір: робота, спортзал, побут).
- Кнопка "Експортувати прогрес" / "Імпортувати прогрес" — щоб переносити дані між пристроями без бекенду.
- Озвучка слів через `SpeechSynthesis` (безкоштовно, вбудовано в браузер).
- Статистика по днях (скільки слів вивчено за тиждень) — простий графік на основі збережених дат.
