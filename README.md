# Базис — версія з навігацією

Повна структура застосунку: постійна нижня панель навігації (як у мобільних застосунках), модульна граматика з окремими статтями, довідка (IPA + частини мови), налаштування розміру шрифту, і виправлення UX (фіксовані кнопки, індикатор прокрутки, вимкнений подвійний тап-зум).

## Структура файлів

```
index.html                — Слова: вибір теми
trainer.html                — тренажер карток (параметризований ?topic=)
grammar.html                 — Граматика: вибір статті
grammar-tenses.html           — стаття: часи (3 рівні за частотою вживання)
grammar-articles.html          — стаття: артиклі a/an/the
grammar-prepositions.html       — стаття: прийменники часу in/on/at
reference.html                   — Довідка: як читати IPA + частини мови
settings.html                     — Налаштування: розмір шрифту
styles.css                         — спільна тема для всіх сторінок
app.js                              — спільний код (світлячки, service worker, шрифт, індикатор скролу)
manifest.json, sw.js                — PWA
data/core.json, data/environment.json — дані тем
fonts/                                — локальні шрифти
```

## Що нового в цій версії

**Постійна нижня навігація.** На кожній сторінці внизу — 4 вкладки: Слова, Граматика, Довідка, Налаштування. Активна вкладка підсвічена золотим. Це вирішує проблему "незрозуміло де я і як переключитись" — навігація завжди на тому самому місці, а не дрібним текстом у кутку.

**Граматика стала модульною.** Замість однієї довгої сторінки — `grammar.html` тепер список статей (як домашній екран для слів), кожна стаття відкривається окремо. Додано дві нові статті: **Артиклі** (a/an/the/нульовий артикль) і **Прийменники часу** (in/on/at). Обидві звірені з Cambridge Dictionary (English Grammar Today) та British Council LearnEnglish.

**Довідка (`reference.html`)** — два розділи: як читати транскрипцію IPA (таблиця стандартних 44 фонем британської англійської — 12 голосних, 8 дифтонгів, приголосні що відрізняються від звичних літер, кожен з прикладом слова) і що означають скорочення частин мови (noun/verb/adjective тощо) українською.

**Налаштування (`settings.html`)** — регулятор розміру шрифту (4 рівні), впливає на весь застосунок одразу через CSS-змінну `--fs`, зберігається в localStorage.

**UX-виправлення в тренажері:**
- Кнопки "Знаю"/"Забув" тепер завжди на фіксованому місці внизу картки, не "стрибають" залежно від довжини тексту
- Якщо текст картки не влазить і потребує прокрутки — з'являється легкий фейд-градієнт знизу як сигнал "тут ще є текст"
- Подвійний тап для зуму вимкнено (`user-scalable=no` у viewport) — весь інтерфейс і так адаптований під екран
- Кнопки мають `touch-action: manipulation` для швидшої реакції на дотик

**Формат тем для IELTS збагачено.** Environment тепер має по два приклад-речення на кожне слово замість одного — тест "детальніших пояснень", про які говорили.

## Технічна примітка про переклад позначок частин мови

Свідомо залишив жовтий кружечок з англійськими скороченнями (noun/verb/adjective), а не переклав на українську — бо звикання до цих термінів самих по собі корисне (вони трапляються в будь-якому словнику). Натомість пояснення винесено в Довідку окремим міні-туторіалом, щоб не перевантажувати саму картку.

## Розміщення на GitHub Pages

Без змін у принципі — заливаєш усю структуру папок як є (`data/` і `fonts/` підпапками), вмикаєш Pages. `start_url` в маніфесті вказує на `index.html`.

## Що ще залишається в плані (не зроблено зараз)

- Наповнення решти тем IELTS (Education, Technology, Health тощо) — свідомо відкладено до другої фази, як домовились
- Додаткові статті граматики (фразові дієслова, обчислювані/необчислювані іменники) — місця для них уже зарезервовані в списку `grammar.html` з позначкою "скоро"
- Індикатор "тема ще не заповнена" на домашньому екрані слів (коли з'являться нові теми з тисячами слів, а не тільки Environment)
